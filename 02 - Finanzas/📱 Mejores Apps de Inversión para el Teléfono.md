## ✅ Checklist Antes de Instalar/Elegir

```
[ ] Probá app demo 15 min: navegá, orden simulada, gráficos
[ ] Verificá biometría: FaceID/TouchID instantáneo
[ ] Testear push: Alerta precio → Cerrar app → Esperar notificación
[ ] Widgets: Agregar a pantalla inicio → Verificar auto-update
[ ] Sync: Cambio en web → Abrir app → ¿Actualizado?
[ ] Soporte: Chat in-app → Medir tiempo respuesta real
[ ] Export: Reporte mensual → ¿CSV/PDF limpio para contador?
[ ] Fees: Ver comisiones REALES (no promo) en web oficial
[ ] Regulación: ¿CNV/BCRA/FCA/SEC/CySEC según corresponda?
[ ] Custodia: ¿Seguro SIPC/$500k? ¿Fondo garantía local?
```
