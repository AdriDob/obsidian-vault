# 🏦 CEDEARs: Guía Completa (2026)

> **Certificados de Depósito Argentinos**. La forma más accesible de invertir en acciones/ETFs extranjeros desde Argentina sin abrir cuenta en el exterior.

---

## 📖 Qué es un CEDEAR

| Concepto | Detalle |
|----------|---------|
| **Definición** | Título valor que representa acciones de empresas extranjeras o ETFs, depositadas en custodia en el exterior (Bank of New York, Citibank, JPMorgan) y negociadas en BYMA (Bolsas y Mercados Argentinos) |
| **Emisor** | Banco custodio local (Banco Galicia, BBVA, Macro, ICBC, etc.) |
| **Subyacente** | 1 acción / ETF del exterior = **Ratio** CEDEARs (ej: 1 AAPL = 10 CEDEARs AAPL) |
| **Moneda cotización** | Pesos argentinos (ARS) en BYMA |
| **Liquidación** | T+1 (igual que acciones locales) |
| **Custodia** | En cuenta comitente del broker argentino (IOL, Cocos, Balanz, etc.) |
| **Derechos** | Dividendos (cobro en pesos al tipo de cambio MEP), voto (limitado), split/bonificación |

## 💰 Arbitraje MEP / CCL (El Motor de Precio)

### **Fórmula Precio Teórico (Fair Value)**
```
Precio CEDEAR (ARS) = Precio Acción Exterior (USD) × Tipo de Cambio Implícito ÷ Ratio
```

### **Tipos de Cambio Implícitos**
| Dólar | Uso | Fórmula |
|-------|-----|---------|
| **MEP (Dólar Bolsa)** | Compra CEDEAR → Venta 24hs → Pesos | Precio CEDEAR (ARS) ÷ (Precio USD × Ratio) |
| **CCL (Contado con Liqui)** | Compra CEDEAR → Transferencia exterior → USD | Precio CEDEAR (ARS) ÷ (Precio USD × Ratio) |

### **Spread Normal vs Oportunidad**
| Situación | Spread MEP vs CCL | Acción |
|-----------|-------------------|--------|
| **Normal** | 1-3% | No hay arbitraje puro |
| **CEDEAR caro (MEP > CCL + 2%)** | MEP sobrevalúa | Vender CEDEAR → Comprar dólar MEP |
| **CEDEAR barato (MEP < CCL - 2%)** | MEP subvalúa | Comprar CEDEAR → Vender dólar MEP (si tenés USD afuera) |

### **Ejemplo Práctico (Agosto 2026)**
```
AAPL NASDAQ: $220 USD
Ratio AAPL: 10:1
CCL: $1.350 ARS
MEP: $1.320 ARS

Fair Value CCL = 220 × 1.350 ÷ 10 = $29.700 ARS
Fair Value MEP = 220 × 1.320 ÷ 10 = $29.040 ARS

Si CEDEAR cotiza $30.500 → Caro vs MEP (2.6% premium) → Vender CEDEAR + Comprar MEP
Si CEDEAR cotiza $28.200 → Barato vs MEP (2.9% discount) → Comprar CEDEAR + Vender MEP
```

## 📅 Dividendos CEDEARs: Cómo Funcionan

| Paso | Qué Pasa | Timing |
|------|----------|--------|
| 1 | Empresa exterior declara dividendo | Fecha ex-dividendo (ex-date) |
| 2 | Custodio exterior recibe USD | ~2-4 semanas post ex-date |
| 3 | Custodio convierte a ARS al **MEP del día de pago** | Crítico: tipo de cambio = MEP |
| 4 | Broker argentino acredita en cuenta comitente | T+1 post conversión |
| 5 | Retención 7% (Impuesto Ganancias EE.UU. - Convenio) | Automático |
| 6 | Vos recibís ARS netos | Disponible para reinvertir/retirar |

### **Ejemplo Dividendo AAPL**
```
AAPL declara $0.25/acción trimestral
Tenés 100 CEDEARs AAPL (equivale 10 acciones)
Dividendo bruto: 10 × $0.25 = $2.50 USD
MEP día pago: $1.320
Brutos ARS: $2.50 × 1.320 = $3.300 ARS
Retención 7%: -$231 ARS
Netos en cuenta: $3.069 ARS
Rendimiento efectivo ARS: $3.069 / (100 CEDEARs × precio_compra)
```

## 🇦🇷 Ventajas CEDEAR vs Acción Directa (IBKR)

| Factor | CEDEAR (IOL/Cocos) | Acción Directa (IBKR) |
|--------|-------------------|----------------------|
| **Apertura cuenta** | 100% online, 24-48h, solo DNI | 100% online, 1-3 días, W-8BEN, selfie, prueba domicilio |
| **Funding** | Transferencia ARS instant (CVU/CBU) | SWIFT USD (1-3 días, $10-50 fee) o Takenos/Wise |
| **Mínimo inversión** | 1 CEDEAR (~$3.000-50.000 ARS) | 1 acción fraccionada ($1 USD) / 1 acción entera |
| **Dividendos** | Automático en ARS (MEP) | USD en cuenta → vos convertís |
| **Bienes Personales** | **EXENTO hasta $100M** (BYMA) | **TRIBUTA FULL** (valuación 31/12 × TC) |
| **Ganancia Capital** | 15% (exento < $1.5M/año) | 15% (misma regla) |
| **Horario trading** | 11:00-17:00 HS (BYMA) | 10:30-17:00 ET (pre/post market 4:00-20:00 ET) |
| **Liquidez** | Media (top 20) | Altísima (mercado US) |
| **Dólar implícito** | MEP/CCL (volátil) | USD real (spot) |
| **Riesgo custodia** | Broker AR + Custodio local + Custodio ext | IBKR (SIPC $500k + Lloyd's) |
| **Reportes fiscales** | Certificado retención local | Tax Statement (1042-S, 1099) + manual AR |

## ⚠️ Riesgos Específicos CEDEARs

| Riesgo | Descripción | Mitigación |
|--------|-------------|------------|
| **Riesgo cambiario MEP/CCL** | Precio CEDEAR sigue dólar financiero, no necesariamente fundamentals | Diversificar en ETFs broad (SPY, VT) + mantener cash USD afuera |
| **Riesgo custodia cadena** | Broker AR → Custodio local → Custodio exterior (3 eslabones) | Usar brokers top 3 (IOL, Cocos, Balanz) + CNV regulado |
| **Riesgo regulatorio AR** | Cambios cepo, restricciones CEDEARs, nuevo impuesto | Monitorear CNV/BCRA/AFIP, tener plan B (IBKR) |
| **Liquidez baja (chicos)** | Spreads anchos, difícil salida montos grandes | Solo top 20, operar en tramos, órdenes límite |
| **Tracking error** | CEDEAR ≠ acción 1:1 por ratio, dividendo MEP, gastos custodia | Aceptar 0.5-1.5% tracking error anual |
| **Dólar MEP vs CCL gap** | Si MEP << CCL, CEDEARs cotizan con descuento vs fair value CCL | Entender qué dólar usa tu broker para valuación |

## 🛒 Cómo Comprar tu Primer CEDEAR (Paso a Paso IOL)

```
1. ABRIR CUENTA IOL
   → Web/App → "Abrir Cuenta" → DNI + Selfie + CBU/CVU → 24-48h

2. FONDEAR
   → Transferencia desde banco/MP/Ualá a CVU IOL (instant, $0)
   → Mínimo sugerido: $50.000 ARS (para lote decente SPY/QQQ)

3. BUSCAR TICKER
   → App IOL → Buscar "SPY" → Ver precio, spread, volumen

4. COLOCAR ORDEN
   → Tipo: Límite (precio max) / Mercado (instant)
   → Cantidad: En CEDEARs (ej: 50 SPY = 5 acciones SPY)
   → Validez: Día / 30 días

5. CONFIRMAR
   → Revisar: Precio × Cantidad + Comisiones + Sellos + IVA = Total ARS
   → Biometría → Enviar

6. SEGUIMIENTO
   → Portfolio → Ver posición → Alertas precio → Dividendos
```

## 📋 Checklist Antes de Comprar CEDEARs

```
[ ] Entendí el ratio (cuántos CEDEARs = 1 acción)
[ ] Verifiqué fair value vs MEP/CCL hoy (no pagar premium > 2%)
[ ] Elegí broker: IOL (mejor app) / Cocos (cripto integrado) / Balanz (estable)
[ ] Tengo funding ARS listo (CVU/CBU broker)
[ ] Definí horizonte: largo plazo (años) vs trading (días/semanas)
[ ] Entendí implicancias fiscales: Ganancias 15% / BP exento $100M / Dividendos 7%
[ ] Sé que horario es 11-17hs (no 24/7 como crypto)
[ ] Tengo plan de salida: vender CEDEAR → pesos → ¿qué hago? (MEP, gasto, reinvertir)
[ ] Registré operación en Portfolio Tracker (fecha, precio, qty, fees, broker)
```
