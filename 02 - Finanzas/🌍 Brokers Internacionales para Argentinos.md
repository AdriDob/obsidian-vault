## 🇪🇺 XTB: La Alternativa Europea Sólida

### **Por Qué XTB para Argentino**
- **Regulado CySEC + FCA + KNF** → Pasaporte europeo, protección €20k/£85k
- **xStation 5** → Mejor plataforma desktop/web del mercado (gráficos, screeners, heatmaps)
- **Cuenta remunerada** → 3-4% APY en EUR/USD (hasta €100k) **sin riesgo mercado** (depósito bancario)
- **Spreads reales** → 0.1-0.5 pips forex, 0.08% stocks (modelo agency/no dealing desk)
- **Soporte nativo español** → Chile/México/España/Argentina team

### **Limitaciones XTB**
| Limitación | Impacto |
|------------|---------|
| **Solo CFDs en acciones** (no propiedad real) | No votás, no dividendos directos (ajuste en precio), overnight fees si holding >1 día |
| **Sin opciones reales** | Solo CFD opciones (no exercise, no assignment) |
| **Sin futuros reales** | Solo CFD futuros |
| **Sin API para algo trading** | Solo xStation API (webhook/alertas) |
| **Pies (fraccionadas)** | No nativo (CFD permite tamaño variable pero no ownership) |

> ⚠️ **XTB = CFD Broker**. Si querés **propiedad real (acciones en tu nombre)**, IBKR o Trading 212.

## 🛂 Proceso Apertura IBKR (Paso a Paso 2026)

```
1. ENTRAR: https://www.interactivebrokers.com.ar/ (versión AR) o .com
2. CLICK: "Open Account" → "Individual" → "Non-US Resident"
3. DATOS PERSONALES:
   - Nombre completo (igual pasaporte)
   - Nacionalidad: Argentina
   - Residencia fiscal: Argentina (CUIT)
   - Domicilio: Argentina (factura servicio / extracto banco <3 meses)
4. DOCUMENTOS:
   - Pasaporte (foto clara, vigente)
   - Selfie con pasaporte (app IBKR lo guía)
   - Comprobante domicilio (últimos 3 meses)
5. W-8BEN:
   - Completar online en portal
   - Certificás residencia AR → Dividendos US 15% (vs 30%)
   - Renovar cada 3 años (recordatorio email)
6. EXPERIENCIA/TRADING:
   - Honesto: "Limited" si principiante
   - Habilita: Stocks, ETFs, Options (si querés), Forex
7. FUNDING:
   - Añadir instrucciones: Takenos/Wise/SWIFT
   - IBKR te da: Account Title, Routing (ABA), Account Number (para ACH US)
8. ESPERAR APROBACIÓN: 1-3 días hábiles
9. LOGIN + 2FA: App "IBKR Mobile" + "IBKR Authenticator" (TOTP) o YubiKey
10. PRIMER DEPÓSITO: Takenos → IBKR ACH (instant, ~1%)
```
